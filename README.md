# Teen Fiesta — Red Room

A cinematic Next.js landing page for Teen Fiesta's Red Room event.

## Development

```bash
npm install
npm run dev -- -p 3001
```

Open [http://localhost:3001](http://localhost:3001).

## Checks

```bash
npm run typecheck
npm run build
```

The site uses local media in `public/media` and a custom Three.js starburst rendered with React Three Fiber.
